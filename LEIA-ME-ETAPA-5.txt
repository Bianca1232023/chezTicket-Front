APLICACAO:
- Faça uma cópia local do projeto antes de extrair.
- Do PowerShell em ...\chezTicket-Front\chezTicket:
  Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\chezTicket_etapa5_ajustes_interface.zip" -DestinationPath (Resolve-Path ..).Path -Force
- Ainda em ...\chezTicket-Front\chezTicket:
  cd ..
  npm run build
  npm run dev
- Confira seleção de ingressos pagos, banner de pagamento via Stripe,
  comprovante e imagens sem falhas.

Este pacote inclui APENAS 5 arquivos .tsx do frontend. Não modifica credenciais,
Spring Security, MariaDB, Flyway ou Stripe. Nenhum pagamento adicional é necessário.
